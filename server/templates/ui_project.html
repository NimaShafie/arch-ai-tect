Workflow overview

Follow these steps in order to go from a raw idea to generated diagrams and docs:

  1. Requirements Brief — Describe your system in plain English, then click Interpret with AI. Review / edit the generated brief JSON and click Save Brief.
  2. Generate Architecture — Choose which diagrams to generate and click Generate Diagrams. This uses the saved brief as input.
  3. View Output — Open the generated documentation and diagrams via View Documentation.
