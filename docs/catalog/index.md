# Catalog

Reusable components, patterns, and reference templates for the ArchAiTect Workbench.

At the moment, most of the content lives under individual **Projects**. Over time,
this catalog can collect:

- Shared architecture blueprints (e.g. login systems, streaming platforms).
- Reusable C4 models, sequence diagrams, and deployment topologies.
- Cross-cutting guides (observability, security, CI/CD, etc.).

When a pattern is stable enough to reuse across projects, lift it out of a single
project and document it here.
